Challenge 2 - Point Ratings

The point rating system assigns:

  • 1 point for a win;
  • 0.5 points for a draw;
  • 0 points for a defeat.

To compute the total number of points earned by a player, we define the following function:

rating <- function(scores) {
  sum(scores)
}

Since a player can appear either as White or Black, we first construct a dataset containing all player scores.

player_score <- bind_rows(
  outcomes |>
    transmute(
      player = White,
      score = Score
    ),
  outcomes |>
    transmute(
      player = Black,
      score = 1 - Score
    )
)

The point rating of each player is obtained by summing the scores achieved across all games.

player_ratings <- player_score |>
  group_by(player) |>
  summarise(
    rating = rating(score)

Challenge 3

An interesting property of Elo ratings is that the sum of all player ratings is always \(0\). Formally show this property. (Hint: use the fact that \(s_{i,j} + s_{j,i} = 1\) and \(\mu_{i,j} + \mu_{j,i} = 1\))

Let the set of all players be \(P\). When the system is initialized, every player \(k \in P\) starts with an initial rating of \(0\): \[r_k = 0 \quad \forall k \in P\]

Therefore, the initial sum of all player ratings is exactly \(0\): \[\sum_{k \in P} r_k = 0\]

Consider a single match played between player \(i\) and player \(j\). Their updated ratings (\(r_i'\) and \(r_j'\)) are defined by the Elo update formulas:

\[r_i' = r_i + \kappa(s_{i,j} - \mu_{i,j})\] \[r_j' = r_j + \kappa(s_{j,i} - \mu_{j,i})\]

To find the new combined rating of these two players, we add the two equations together:

\[r_i' + r_j' = r_i + r_j + \kappa \Big[ (s_{i,j} + s_{j,i}) - (\mu_{i,j} + \mu_{j,i}) \Big]\]

Using the given properties of match outcomes and expected scores: * \(s_{i,j} + s_{j,i} = 1\) (The actual scores of both players sum to 1) * \(\mu_{i,j} + \mu_{j,i} = 1\) (The expected probabilities of both players sum to 1)

We substitute these values into the equation:

\[r_i' + r_j' = r_i + r_j + \kappa \Big[ 1 - 1 \Big]\] \[r_i' + r_j' = r_i + r_j + \kappa(0)\] \[r_i' + r_j' = r_i + r_j\]

Because \(r_i' + r_j' = r_i + r_j\), the total rating point exchange between any two players is a zero-sum transaction. Ratings are neither created nor destroyed; they are simply transferred from one player to another.

Since the system starts with a total sum of \(0\) and every individual match strictly preserves this total, the sum of all player ratings remains equal to \(0\) for the entire duration of the Elo process. \(\blacksquare\)

Step 3: Optimized Elo Function

Since the Elo system is zero-sum (\(r_i' + r_j' = r_i + r_j\)), the rating points gained by one player are exactly equal to the points lost by the other. We can calculate the rating shift.

elo_ratings <- function(outcomes,
                        zeta = 400,
                        kappa = 25) {

  players <- sort(
    unique(
      c(outcomes$White,
        outcomes$Black)
    )
  )

  ratings <- setNames(
    rep(0, length(players)),
    players
  )

  for (i in 1:nrow(outcomes)) {

    white <- as.character(
      outcomes$White[i]
    )

    black <- as.character(
      outcomes$Black[i]
    )

    score_white <- outcomes$Score[i]

    score_black <- 1 - score_white

    rating_white <- ratings[white]

    rating_black <- ratings[black]

    mu_white <-
      1 /
      (
        1 +
        10^(
          -(rating_white -
              rating_black)/zeta
        )
      )

    mu_black <- 1 - mu_white

    ratings[white] <-
      rating_white +
      kappa *
      (score_white - mu_white)

    ratings[black] <-
      rating_black +
      kappa *
      (score_black - mu_black)

  }

  tibble(
    player = as.numeric(names(ratings)),
    elo = as.numeric(ratings)
  )
}

Why is the Elo distribution different from the raw point distribution?

  1. A standard point distribution treats every win equally (1 point regardless of the opponent). Elo scales dynamically based on the strength of the opponent. Beating a high-ranked player grants significantly more Elo points than beating a novice.

  2. Because Elo is zero-sum, ratings continuously balance out. The distribution tends to look more Gaussian (bell-shaped) around 0, whereas raw points are strictly bounded by 0 and the number of games played, often leading to heavily skewed, non-normal distributions.

Step 6: Verification of the Zero-Sum Property

We sum the final Elo values across all players to verify that the total net change equals zero.

## [1] -1.577627e-13

The output is an infinitesimally small number close to 0, representing floating-point precision error inherent to computer arithmetic. This confirms the zero-sum property holds.

This stark divergence among elite players happens because raw point ratings strictly reward match volume, allowing an average player to climb the ranks simply by playing an immense number of games. An elite player with a flawless win rate over fewer matches against top-tier opponents will dominate the Elo leaderboard, but fail to break into the top point ratings due to a lack of sheer game volume.

Raw point ratings show a near-perfect positive correlation (0.99) with total games played.

Because point rating systems accumulate values monotonically (1 point for a win, 0.5 for a draw), activity volume dictates the maximum threshold of a player’s raw score. An average player participating in 100 matches has vastly more opportunities to accumulate points than an elite player who only participates in 5 matches, explaining the linear trend line.

In pure theory, Elo ratings should show a flat or near-zero correlation with total games played, because Elo measures skill quality rather than quantity. However, this specific dataset reveals a moderately strong positive correlation of 0.64 between games played and Elo rating.

This unexpected upward trend in Elo can be attributed to two main factors: 1. Selection and Survivor Bias: Stronger players are highly likely to remain active and play more matches over time, while struggling players who lose their initial matches may quickly become inactive or drop out. This leaves a high concentration of high-Elo players in the high-volume game categories. 2. Rating Convergence: Since all players initialize at an arbitrary 0 rating, skilled players require a sustained volume of games to climb away from the baseline and reach their true, higher skill ceilings.
